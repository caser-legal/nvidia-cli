### Known Bug Patterns to Grep For
```bash
# RACE CONDITION: .sheet(isPresented:) + separate state variable
grep -rn ‘.sheet(isPresented:’ —include=‘*.swift’
# If found with separate state being set in the same action = BUG
# Fix: Use .sheet(item:) instead
```

### Bad Pattern (Race Condition)
```swift
@State var selectedItem: Item?
@State var showSheet = false
Button {
    selectedItem = item    // Set state
    showSheet = true       // Sheet captures OLD nil value!
}
.sheet(isPresented: $showSheet) {
    DetailView(item: selectedItem)  // nil on first tap!
}
```

### Good Pattern (No Race Condition)
```swift
**State variable declaration:**

```swift
@State var selectedItem: Item?
```

**Button:**

```swift
Button { selectedItem = item }
```

**Sheet:**

```swift
.sheet(item: $selectedItem) { item in
    DetailView(item: item)  // Always correct value
}
```
